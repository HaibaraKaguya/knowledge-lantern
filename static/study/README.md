# 知题静态交互原型

这是独立、无后端的移动优先演示，用确定性样例展示拍照记录、记录库、混合检索和回顾四个界面。

直接在浏览器打开 `index.html` 即可。界面中的 OCR、BM25、向量、图谱、AI 总结均为清楚标记的模拟结果；不会上传图片或查询真实数据库。

设计约束：记录库的筛选/排序是稳定的结构化查询，检索页才展示语义检索、RRF 后的证据和“为什么推荐”。

## 「识别」页（真实 OCR 接入）

新增的「识别」页调用本机 FastAPI 的 `/api/study/ocr/*`（本机 LearningOCR 适配层），
**不是演示数据**：可上传图片或填写受控上传目录内的相对引用，提交后展示结构化主记录、
校验警告与 mock/real 标志。

- 该页必须经 FastAPI（`:8000`）访问，例如 <http://127.0.0.1:8000/static/study/index.html>；
  直接以 `file://` 打开时无法访问 API，页面会提示。
- 图片只写入受控目录 `data/study_ocr/uploads/`；结果分「主记录」与「审计 sidecar」两份，
  存在 `data/study_ocr/results/`。
- mock 模式无需模型权重；real 模式需要 OCR 引擎与视觉模型权重齐备，
  状态以 `/api/study/ocr/health` 的返回为准。
